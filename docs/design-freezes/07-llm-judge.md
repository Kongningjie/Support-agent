# LLM-as-Judge 辅助评测冻结方案

确认日期：2026-10-13。对应评测专项批次3；实施依据为[单批次计划](../implementation-plan/17-llm-judge-implementation-plan.md)。

Judge独立于Chat，仅管理员手动执行已脱敏人工样本。输入不包含人工分数、评审人或生成模型名；人工未决时隐藏Judge结果。五维整数0～2分、短理由、Unicode证据半开区间须严格校验，敏感输出不得入库。

每份样本串行评3次，单次超时60秒、输出1500 Token、输入预估上限8000 Token；默认关闭，不自动继承Chat模型。操作幂等，进程并发1，MySQL保障样本活动占用；执行租约240秒，超时不自动再调用。故障记安全分类，不能伪造零分。模型调用在事务之外。

保存模板哈希/Schema版本、模型、结构化结果、耗时与供应商Token用量；未知用量保持为空，不保存渲染Prompt或原始完整响应。每份样本每个模型/模板版本只取最新运行，按版本独立报告；报告最多读取最近1000条运行，截断不能报告验收通过。

人工最终评分是真值。至少30份三次均有效的独立样本，逐维精确一致率≥80%、MAE≤0.3、复测完全一致率≥90%，方可报告辅助评审数值门槛通过；这不代替发布门禁、硬规则或来源偏差审查。人工副本缺少来源模型元数据，必须标记同源偏差未验证。样本类别覆盖和人工内容质量须另行校准，不把离线结构测试当作在线质量证明。

前后端质量门禁及真实后端浏览器联调必须记录；真实Judge调用需单独指定模型和预算。当前未授权在线调用。
