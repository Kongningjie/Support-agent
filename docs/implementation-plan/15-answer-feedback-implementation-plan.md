# 用户回答反馈单批次实施计划

> 状态：已冻结；对应 [用户回答反馈冻结方案](../design-freezes/05-answer-feedback.md)；本次仅执行评测体系优化专项批次 1。

## 交付顺序

1. 追加 Flyway 迁移，建立 `answer_feedback`，使用运行 UUID 唯一约束、递增版本及无内容删除标记防并发 ABA。通过现有 `agent_run` 验证成功状态与本人归属。
2. 在应用层建立反馈用例、字段校验和存储端口；基础设施用 MyBatis 实现带版本条件的原子创建、更正与删除；接口层提供本人 CRUD 和管理员聚合只读接口。
3. 会话详情公开每轮 `runId`；聊天页对 SSE 完成回答与历史成功轮次呈现反馈操作、当前结果和错误反馈。前端通过现有 Axios 客户端访问后端。
4. 增加单元、Controller、MySQL 集成和前端单元测试，执行冻结方案规定门禁；完整 Review，记录真实结果与未验证项。

## 阶段边界

仅这一个批次，完成即停止。不得实现人工标注页面、抽样/脱敏管线、评测集晋升或 Judge 模型调用；不得因反馈自动修改聊天、知识或工单结果。
