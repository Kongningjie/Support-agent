# 人工评测单批次实施计划

> 状态：已冻结；依据[人工评测冻结方案](../design-freezes/06-human-evaluation.md)。仅执行评测体系优化专项批次 2。

1. 追加 Flyway 迁移，建立脱敏样本、独立评审、晋升审计与数据集版本；添加来源唯一性、评审人唯一性和必要索引。
2. 在应用层实现候选只读抽样、显式脱敏副本创建、盲评、分歧复核、开发集纳入与回归集单独审批；MyBatis 负责短事务和并发约束。
3. 提供 `ADMIN` 专用 API、中文 OpenAPI 字段说明及 PowerShell/HTTP 调用示例；前端增加管理员评审页面，真实后端交互，不能以静态样本伪造结果。
4. 运行 `mvn test`、`mvn verify -Pintegration`；前端运行格式、Lint、类型、单测、构建，适用时执行真实后端 E2E；记录任何未验证项并完整 Review。

本批次不调用 DashScope、不实现 Judge、不自动晋升现有固定数据集，也不修改用户反馈的本人 CRUD 语义。完成后停止，等待用户决定是否提交或继续。
