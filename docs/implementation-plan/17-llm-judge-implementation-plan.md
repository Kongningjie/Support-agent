# LLM-as-Judge 单批次实施方案

> 2026-10-13；状态：用户已确认并冻结，实现及离线/集成/无需模型的浏览器门禁完成；真实在线质量校准待执行。对应评测体系优化专项批次 3。真实在线调用预算尚未授权。

## 1. 范围和交互

复用人工评测管理员页面。管理员显式选择一份已脱敏样本执行 Judge，读取五维评分、逐维理由和证据位置，并在人工结论形成后查看对照报告。输入只使用样本的问题、回答和允许展示的证据；不给模型人工分数、评审人、来源模型名称或原会话内容，以免影响独立评分。

Judge 不修改人工评分、样本状态或数据集晋升结果，也不进入在线用户问答链路。未决人工样本可以运行 Judge，但评分结果在人工结论形成前对评审页面隐藏，避免影响盲评。普通用户无访问权限。

## 2. 模型和执行建议

- 沿用 DashScope，通过独立 `JudgeModelPort` 和独立配置指定评审模型；不直接复用 Chat 适配接口或 Chat 默认模型。Judge 默认关闭，模型配置为空时拒绝执行。
- 具体模型由管理员按可用模型配置。与回答模型同系列时记录同源偏差限制；仅更换模型名称不能证明评审独立。当前人工样本没有生成模型元数据，来源未知时报告标为未知，不编造比较结论。
- 一次操作只评一份样本，串行重复 3 次以衡量复测稳定性；单进程最多允许一个评测操作执行，无等待队列，忙时返回冲突。模型调用在数据库事务之外执行。
- 每次模型调用超时 60 秒、输出最多 1500 Token；输入最多预估 8000 Token，超限拒绝而非静默截断。预估预算和供应商实际用量分别记录，无法得到实际用量时标记未知。
- 每次操作最多 3 次模型请求，不自动重试；部分失败仍记录有效次数和失败分类，不补造零分。三次都有效才输出完整稳定性结果。
- 请求使用幂等标识，重复请求不重复消耗额度；已完成结果可查询，新复测必须使用新标识。部署仍为单体，跨进程的同样本重复执行由 MySQL 唯一约束/执行占用控制。

## 3. 输出字段与校验

每次评审必须包含事实正确 `factual`、引用支持 `citation`、完整性 `completeness`、可操作性 `actionability`、表达清晰度 `clarity` 五维整数 0～2 分。每维提供 `reason`（可公开的简短评分依据，不要求隐藏推理），以及 `evidenceStart` / `evidenceEnd`（证据文本中从 0 起的 Unicode 字符半开区间）；无可定位证据时为空并说明理由，不得虚构位置。

严格校验 JSON 结构、维度完整性、整数范围、理由长度、证据区间与敏感信息。模型输出视为不可信数据；问题、答案和证据通过转义数据区隔离，禁止将其中的评分指令当作系统指令。无引用义务的样本遵守人工量表，不能由未填写字段隐式决定。

保存操作标识、样本标识、操作者、模型名称、Prompt/Schema 版本、每次结构化评分、理由及位置、UTC 时间、耗时、用量和安全失败分类。不保存原始完整模型响应或 Prompt，不向普通日志输出样本正文。

## 4. 对照与量化报告

人工已决样本使用最终人工五维评分作真值。报告逐维绝对误差、精确一致率、平均绝对误差（MAE）、Judge 三次评分一致率、有效/失败次数、耗时与实际 Token 用量；聚合报告按样本计算，不能把三次复测当成三个独立样本。

建议校准集至少 30 份真实人工已决样本，覆盖回答类别和低分困难样本；不足时显示样本不足，不宣称质量验收通过。建议辅助评测可用门槛：逐维精确一致率至少 80%、逐维 MAE 不超过 0.3、有效样本复测精确一致率至少 90%。这是待确认的工程门槛，不是已有模型能力结果。模型或 Prompt 版本不同的运行分别统计。

报告列出高估/低估样本与失败分类，供人工复核。确定性安全、权限和引用硬规则继续独立运行，不能由 Judge 高分覆盖。

## 5. 交付与门禁

在现有六模块内实现用例、Judge 端口与 DashScope 适配、MySQL 迁移及幂等结果存储、ADMIN API、前端管理员入口、中文字段说明与 HTTP 示例。不增加依赖、中间件或通用任务类型。

测试覆盖权限、盲评结果隐藏、注入输入、输出缺维/越界/敏感内容、证据位置、超时、部分失败、幂等/并发、人工对照与版本隔离。执行 `mvn test`、`mvn verify -Pintegration`、前端五项质量门禁及真实后端浏览器联调，完成完整 Review，更新后端和前端工作记录。

真实模型质量校准需要已决人工样本及当次在线授权。建议先以 3 份样本 × 3 次调用验证连通性和评分契约，预算最多 9 次调用；输入和输出上限合计不超过约 85500 Token 的预估请求预算（供应商计费可能另有推理 Token）。该预算尚未获得授权。30 份人工校准及同源偏差对比另行明确预算；未执行时不能宣称模型质量门槛通过。

完成本批次后停止，不自动提交或推送。

## 6. 已实现操作与字段说明

管理员打开人工评测样本后，可执行Judge、查询最近20次运行和查询人工一致性报告。服务端默认`SUPPORT_AGENT_JUDGE_ENABLED=false`、`SUPPORT_AGENT_JUDGE_MODEL`为空；获得评测授权后使用环境变量指定可用模型，沿用既有DashScope密钥与Base URL，重启服务。页面不接收密钥。一次操作最长约180秒，结果不确定时复用原幂等UUID；进程崩溃后原Key不会自动调用，租约过期显示失败，新操作释放过期占用。

`signedMeanErrors`是逐维平均Judge分减人工分，正数为高估，负数为低估；`meanAbsoluteErrors`是逐维平均绝对误差；`exactAgreementRates`是逐维相同分数比例；`repeatStable`仅在三次均有效时表示五维分数是否完全一致。维度顺序固定为事实、引用、完整、操作、清晰。

单运行详情含安全的逐维理由和证据位置。聚合报告每份样本只返回数值摘要，避免扩散正文；实际Token任一次未知时总用量为空。最近1000条运行窗口被截断时`truncated=true`且不能通过质量门槛。来源回答模型缺失时`sourceModelBiasUnverified=true`，数值门槛通过不代表同源偏差已验证。
