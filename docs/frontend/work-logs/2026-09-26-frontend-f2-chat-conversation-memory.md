## 目标、验收与范围

- 目标：基于后端真实 REST 与 POST SSE 契约，实现可信聊天、会话生命周期和用户可控长期记忆。
- 修改范围：`support-agent-web/`、前端阶段计划状态、当前系统基线和本记录。
- 不实现：工单创建与流转、管理员治理、后端接口修改、F5 Playwright 最终验收。
- 开始时 Git 状态：`main` 与 `origin/main` 一致，工作区干净。

## 进度

### 已完成实现

- 新增 POST SSE 增量解析器，支持任意 Chunk、CRLF、多行 `data`、注释心跳、UTF-8 流解码和结束冲刷。
- 新增聊天流客户端，处理 Bearer、HTTP 错误、严格递增序号、外层事件一致性、主动取消、异常断流和终止事件。
- 新增聊天 Store 与页面，支持新会话、继续对话、多阶段进度、安全片段、完整答案、引用卡片、建议提示、取消及复用 `clientMessageId` 的显式重试。
- 新增会话列表、详情恢复、重置、删除、过期处理及 409 后刷新最新版本。
- 新增长期记忆设置、分页、状态筛选、候选确认、正文更正、固定、失效时间、撤销和永久删除；写操作携带版本与独立幂等键。
- 新增 `markdown-it html=false` 与 DOMPurify 双重净化组件，只允许普通 Web 或站内链接，不把模型文本当作原始 HTML。
- 更新主导航和路由；工单草稿创建仍属于 F3，本阶段只展示真实建议及有效期，不提前调用建单接口。

### 风险、限制与清理结果

- F2 在线联调创建的一条长期记忆和一条重置会话已在验证永久删除后清理；长期记忆开关恢复为关闭。
- 保留一条聊天回归会话和一份已发布的 F2 MySQL 排查知识，供后续 F3 建单建议及 F5 端到端回归使用；它们均为本地测试数据。
- 当前协议不支持 SSE 断线续传，前端只允许用户复用原 `clientMessageId` 显式重试，这是冻结契约而非遗留缺陷。
- F3 尚未实现；F2 的建议按钮只展示真实建议和有效期，不提前创建工单。
