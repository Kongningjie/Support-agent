- F4 新增平台管理员知识空间页面，覆盖筛选、详情、创建、修改、停用和重新启用。
- F4 新增平台管理员成员治理，覆盖成员分页、新增、恢复、改角色和撤销。
- 写操作沿用后端现有 `Idempotency-Key`、`expectedVersion`、角色枚举和稳定错误码，不新增接口或状态。
