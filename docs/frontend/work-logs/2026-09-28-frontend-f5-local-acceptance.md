## 实施、测试与 Review

### 已完成实现

- 引入冻结技术栈中的 Playwright `1.63.0` 并精确锁定版本，增加本机地址限制、单 Worker 串行执行、进程环境凭据和真实后端专用账号准备逻辑。
- 统一补齐普通 REST `410` 和 Chat `502` 安全文案；为网络、SSE 未完整终止以及 `410/502/503` 增加回归测试。
- 修复多个列表错误状态未传递 `retryable`、导致真实网络或依赖故障看不到重试入口的问题。
- 增加跳转主要内容链接、窄屏导航可访问名称、统一焦点轮廓、对话框视口上限及可点击表格行的空格键操作。
- 移除聊天输入区重复的粘性定位，避免其覆盖回答末尾和建议建单操作；验收截图确认消息与输入区不再遮挡。
- Playwright Trace 和 Video 默认关闭，避免认证 Header 或测试密码进入可分享测试报告；显式验收截图只保存在 Git 忽略目录。
- 补充前端 README 的 E2E 环境变量、浏览器安装、账号准备、在线授权和清理说明。
