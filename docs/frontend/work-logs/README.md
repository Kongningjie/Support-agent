# 前端阶段工作记录

本目录只记录前端阶段 F1～F5 的实际实施、测试、联调和 Review 证据，不把计划内容写成已完成结果。

## 命名规则

文件名使用 `YYYY-MM-DD-frontend-fN-<stage-name>.md`，例如：

```text
2026-09-26-frontend-f1-foundation-auth.md
```

## 使用方式

1. 开始阶段时复制 [模板](TEMPLATE.md)，立即填写目标、范围和初始 Git 状态。
2. 实施中持续记录契约差异、用户确认和真实联调结果。
3. 结束时补齐文件变化、命令结果、Review 问题、处理结果和未验证项。
4. 未完成测试或真实联调时不得把阶段标记为“已完成”。
5. 每次提交前必须先完成记录和完整差异 Review。

判断最近记录时只读取以日期开头的文件；`README.md` 和 `TEMPLATE.md` 不属于阶段结果。
