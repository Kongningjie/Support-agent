# LLM-as-Judge 批次工作记录

日期：2026-10-13。状态：实现及离线、集成、无需模型的真实浏览器门禁完成；在线质量校准未执行。依据：`docs/implementation-plan/17-llm-judge-implementation-plan.md`及`docs/design-freezes/07-llm-judge.md`，用户已确认。

范围：独立 Judge、脱敏样本评审、三次复测、管理员接口和前端、人工对照报告。真实模型预算未授权。

## 实施内容

- 独立JudgeModelPort及DashScope适配；UTF-8评审模板、模板哈希/Schema版本、严格五维JSON与重复键校验、转义数据区。默认关闭，无Chat模型回退。
- 单进程并发1、单次操作三次串行复测、每次60秒/1500输出Token、含XML转义扩张的输入预算。显式SDK maxAttempts=1，失败不额外重试；模型请求在数据库事务之外。
- V12 Judge运行表与MyBatis持久化；操作者幂等唯一键、样本活动占用唯一键、240秒租约、过期不重放。只保存已校验结构化结果及安全失败分类。
- ADMIN执行/查询/版本报告API和中文字段说明；人工未决时隐藏分数、理由与对照。按每样本每模型模板版本的最新运行去重，报告MAE、一致率、复测稳定性、正负误差、失败、耗时和实际用量；聚合不返回评分正文。
- 管理员Judge面板、长请求幂等复用、执行确认、中文状态、无样本/失败提示；修复人工评测页表格未注册的渲染问题，固定用例选择使用现有原生选择框模式，表格操作按ID查找类型化数据。

- 单元测试覆盖幂等、盲评隐藏、部分失败、敏感理由、非法分数/证据位置、预算及转义扩张、未配置、过期不重放、并发拒绝、样本去重与版本独立门槛。本机HTTP IT验证供应商Token解析、材料边界转义及HTTP500只有一次请求。
