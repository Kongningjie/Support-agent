## 阶段目标与边界

- 实现本地用户名密码、Redis 不透明 Bearer Token、`USER`/`ADMIN` 两级角色及管理员创建和禁用用户。
- 将 Redis 会话、工单和 Agent 运行绑定公开 `userId`，并在应用层执行资源归属校验。
- 旧无归属 Redis 会话自然过期；旧无归属工单仅管理员可访问。
- 不实现会话列表、详情、重置、删除、长期记忆、改密、管理员重置密码、账号锁定或真实 SSO。

## 已完成工作

- 已完成执行前计划、规范、阶段 10 工作记录、分支和工作区检查。
- 阶段 10 已提交并推送至 `origin/main`，提交为 `c9cc506`，阶段 11 从干净工作树开始。
- 新增本地用户聚合、MySQL `app_user` 表、BCrypt strength 12 密码哈希、首次管理员引导和 `USER`/`ADMIN` 两级权限。
- 新增 Redis 不透明 Bearer Token：原始 Token 仅返回客户端，Redis 只保存 SHA-256；固定 TTL 2 小时，支持单 Token 注销和禁用用户时全量撤销。
- 新增按用户名或来源分别生效的登录失败限流；不存在用户仍执行 BCrypt 虚拟校验，避免明显的用户名时序差异。
- 新增登录、注销、本人信息、管理员创建用户和启停用户接口；创建用户接入已有幂等框架，幂等指纹不持久化密码或密码快速摘要。
- 将 Redis 会话、工单和 Agent 运行绑定公开 `userId`；普通用户仅访问本人资源，管理员可访问全部工单，历史无归属工单仅管理员可见，历史无归属会话不可接管。
- 将请求内固定操作者替换为认证用户 UUID；无请求上下文的异步任务继续使用稳定系统身份。
- Spring Security 只允许登录、健康检查和 OpenAPI 匿名访问；用户管理、知识、案例、异步任务和评测接口仅管理员可用。
- 排除 Spring Boot 默认内存用户自动配置，避免生成与本项目认证链路无关的随机开发密码。

## 文件与契约变化

- `support-agent-domain`：新增 `UserAccount`、`UserRole`、`UserStatus`，工单新增 `ownerUserId`。
- `support-agent-application`：新增认证及用户管理用例和端口；Chat、会话存储、工单命令与查询显式接收认证用户。
- `support-agent-infrastructure`：新增 Flyway V5、用户 MyBatis 持久化、BCrypt、Redis Token 与登录限流适配器；会话、工单和审计持久化加入归属校验。
- `support-agent-interfaces`：新增 Spring Security 过滤链、统一 401/403 响应和认证/用户管理 API；SSE 的初始请求仍认证，Servlet `ASYNC` 二次派发放行。
- `support-agent-bootstrap`：新增认证装配和环境变量占位；`.env.example` 只保存空占位，不包含真实密码或密钥。
- 新增公开请求字段 `idempotencyKey`：管理员创建用户的 1～160 字符客户端幂等键。
