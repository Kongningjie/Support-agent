## 2. 范围与结果

- 新增 80 条自编中文固定安全样本：直接注入 20、间接注入 20、输出泄漏或危险内容 15、困难正常样本 25；不含真实凭据、真实个人信息或生产正文。
- 新增严格 JSONL 加载器、来源与动作契约校验、生产策略复用评测服务和无正文聚合报告。离线结果：直接注入阻断率 100%、间接注入上下文逃逸 0、危险输出逃逸 0、困难正常样本误阻断率 0，全部逐样本动作与信号断言通过。
- 新增 `LlmSecurityTelemetryPort` 与 Micrometer 适配器，记录 Prompt 评估、上下文排除、输出评估、完整重生成和最终拒绝。标签仅使用 `source`、`action`、`signal`、`branch`、`rule` 的冻结值；未知规则折叠为固定 `NONE`。
- Prompt 和输出策略故障均保持失败关闭：输入异常不取得会话租约、不调用模型；输出异常不会被转换为 `PASS`。阶段 16 的不发送失败正文、不提交半轮会话和不持久化业务草稿边界保持不变。
- 未新增公共 API、SSE 事件、数据库表、中间件或技术依赖，也未改变 readiness 语义。

## 5. 风险与后续验证

- 离线 100% 结果只适用于当前 80 条固定样本和确定性生产策略，不能代表开放世界攻击覆盖率。
- 真实 DashScope 模型可能改变输出形态、延迟和 Token 成本；必须在用户单独授权后运行在线对抗评测并单独记录结果。
