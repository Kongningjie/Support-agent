## 用户确认与开始状态

- 开始时 `main` 工作区无未提交改动；用户确认双人独立评审、分歧由第三人复核、五维 0～2 分、脱敏副本单独存储、开发集/回归集独立晋升，以及管理员读取仅含元数据的无帮助反馈候选。
- 现有 `agent_run` 不保存回答正文；Redis 会话空闲 TTL 为 7 天。反馈候选可能在会话过期后不能建样本，不能自动复制或补造旧回答。

## 实施记录

- 追加 V11 三表：脱敏样本、单人不可变盲评、数据集晋升版本审计；来源和评审人使用唯一约束，行锁串行化并发评分。
- 新增 ADMIN 受限候选、固定用例候选、脱敏样本、盲评、复核及晋升 API；非管理员由安全过滤器与应用层双重拒绝。候选不含用户说明与回答，未决时不返回其他管理员评分。
- 新增管理员页面与 API 客户端、路由、导航和 HTTP 示例。原会话仅在管理员显式点击后预览，创建时须再次确认脱敏。
