## 关键计划决策

- `GLOBAL` 固定 UUID 为 `00000000-0000-0000-0000-000000000001`。
- 历史文档、工单和案例统一迁入 `GLOBAL`；历史 Redis 会话固定按 `GLOBAL` 兼容，不分析正文猜测归属。
- 成员记录采用 `ACTIVE/REVOKED` 状态和乐观锁，重新加入恢复原记录。
- 资源与空间、成员与用户使用禁止级联的数据库外键；空间审计记录保存目标空间 UUID，但不得进入指标标签。
- 文档活动内容唯一性从全局调整为同空间唯一。
- 检索必须在 Elasticsearch BM25、向量召回和 MySQL 来源回查三处使用一致允许空间集合。
- 阶段 18 只建立基础和迁移，不提前启用受限空间检索。
- 阶段 20 最终收紧 `spaceId` 必填前，正式客户端必须通过独立前端计划完成真实联调。
- 轻量级部署、组织架构、多租户、工单协同和跨空间联邦检索不进入阶段 18～20。
