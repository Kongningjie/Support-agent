## 阶段目标与验收标准

- 目标：把原先偏生产级的建议收敛为适合第一次学习的单机部署方案。
- 验收标准：明确部署拓扑、访问边界、实施步骤、交付物、验收门禁、不在范围和执行指令。
- 不在范围：不创建部署脚本或系统服务，不操作云服务器，不修改业务代码，不执行阶段 18。

## 已完成工作

- 冻结阶段 18“轻量级云服务器部署”。
- 确认前端不是部署前置条件，首轮使用 Apifox、Postman 或 IDEA HTTP Client 验证后端。
- 冻结单机拓扑：Docker Compose 运行 MySQL、Redis、Elasticsearch，宿主机系统服务运行可执行 JAR。
- 冻结最小访问边界：仅允许受限 SSH，通过 SSH 隧道访问绑定回环地址的应用，不开放公网业务和数据端口。
- 明确本阶段不引入 HTTPS、高可用、CI/CD、集中监控、托管数据服务或生产 SLA。
- 同步总计划、文档索引与仓库执行约束。
