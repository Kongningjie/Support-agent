## 阶段目标与验收标准

- 实现不依赖 AI 和知识检索的工单草稿、查询、修改、提交和关闭主流程。
- 实现外部请求幂等、工单编号和乐观锁，并保证事务边界正确。
- 实现持久化异步任务的创建、抢占、续租、退避、完成、死亡、取消及人工重试。
- 提供中文 OpenAPI 字段说明与 IDEA HTTP Client 示例。
- 通过单元测试、MySQL 集成测试、HTTP 主路径验证和完整差异 Review。
- 不实现 Chat、知识发布、工单解决、案例生成或任何阶段 3～5 功能。

## 已确认实现边界

- 工单接口仅公开 `ticketNo`，不公开 `ticket.id`。
- 异步任务的 `taskId` 与 `aggregateId` 按十进制字符串公开，但不公开 Worker 锁字段。
- 本阶段只实现通用 `AsyncTaskHandler` 扩展点；生产环境不注册阶段 3/5 的具体 Handler。
- 缺失 Handler 的任务作为不可重试配置错误直接进入 `DEAD`。
- 人工重试要求原聚合状态和版本仍适用，创建新任务且不复活原任务。
- 外部幂等按请求哈希、执行租约、首次成功复用、最终失败复用及可重试失败恢复语义执行。

## 已完成工作

- 完成手工工单草稿创建、详情、分页、修改、提交和关闭用例及 REST 接口。
- 工单编号按内部主键生成 `T` + 12 位数字；写操作执行版本和状态双重校验。
- 完成 MySQL 外部幂等执行器，覆盖请求哈希冲突、处理中租约、成功资源重放、最终失败重放及可重试失败恢复。
- 完成持久化异步任务创建、分页、抢占、续租、成功、固定退避、死亡、取消和人工重试。
- Worker 使用固定并发线程池和 `FOR UPDATE SKIP LOCKED`；租约过期后阻止旧 Worker 回写，最后一次尝试崩溃后自动转为 `DEAD`。
- `AsyncTaskHandler` 仅作为扩展接口，阶段 2 不注册生产处理器；执行上下文提供按需续租回调。
- 完成统一错误映射、中文 OpenAPI 字段说明和 IDEA HTTP Client 示例。
- 将领域层 ArchUnit 门禁移动到领域模块自身，消除同包名适配层被误判的问题。
