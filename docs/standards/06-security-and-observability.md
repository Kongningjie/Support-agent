# 安全与可观测性规范

## 安全

- 密钥、令牌、密码和连接凭据只能通过环境变量或受控配置注入，不得进入源码、测试快照、日志或文档。
- 不记录完整 Prompt、模型完整输出、知识库原文、个人信息或其他敏感数据；确需排障时仅记录脱敏摘要和标识符。
- 所有外部输入都必须校验长度、格式、枚举范围和资源归属；URL、文件路径及命令类输入需要额外防注入检查。
- 模型输出和检索证据均视为不可信输入，使用前必须完成结构、引用和允许动作校验。
- API 不得向客户端暴露堆栈、SQL、内部类名、文件路径或第三方原始错误。

## 可观测性

- 请求链路使用 `traceId`，Agent 执行使用 `runId`；异步任务、检索和模型调用应能关联到同一链路。
- 日志应记录阶段、耗时、结果分类和可操作错误信息，避免只写“失败”或重复打印异常。
- 不输出模型隐藏推理过程；可记录经过设计的步骤摘要、工具调用结果和引用证据。
- 日志级别必须准确：可恢复业务分支不滥用 `ERROR`，真实故障不得降级为 `DEBUG`。
- 合并前删除临时调试日志、固定测试数据和本地环境路径。
